# Portfólio Profissional | Thailson Droid

**Aluno:** Thailson Droid

## Sobre o projeto

Este portfólio apresenta meu perfil, meus projetos acadêmicos e algumas das tecnologias que estou aprendendo. O site foi criado como parte da atividade de desenvolvimento de páginas para a Internet.

## Site publicado

[ Acesse o portfólio no GitHub Pages ](https://thailson-droid.github.io/Portifolio-Profissional/#)

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript do Bootstrap
- Devicon, para os ícones das tecnologias

## Como o projeto funciona

O site é dividido em três seções principais: **Perfil**, **Projetos** e **Contato**. O menu de navegação permite acessar cada seção. O carrossel exibe imagens de apresentação, e os cards mostram informações sobre os projetos. O botão “Ver detalhes” abre uma janela modal com mais informações sobre o primeiro projeto.

O layout utiliza componentes e classes do Bootstrap para organizar o conteúdo e adaptar a página a diferentes tamanhos de tela. O JavaScript do Bootstrap habilita o menu responsivo, o carrossel e a janela modal.

## Recurso novo

Foi adicionada a seção **Formação complementar** ao perfil, com informações sobre o curso de Manutenção de Microcomputadores, realizado no CETEF e concluído em 2026 e uma animação leve no carossel inicial de imagens.

## Como o recurso foi implementado

A seção foi criada em HTML com um título e um card. Para o visual, foram utilizadas classes do Bootstrap, como `card`, `card-body`, `shadow-sm` e `mt-4`. Ela foi posicionada dentro da seção Perfil, depois das tecnologias e ferramentas, adicionado uma animação ao carossel, a animação do carrossel foi feita pelo Bootstrap, usando as classes e os atributos no HTML.
